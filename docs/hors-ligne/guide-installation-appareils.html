Wakara - Travailler sans Internet

Guide d'installation pour ordinateur, Android et iPhone. Pas de connaissance technique nécessaire.

1. Ce qu'il faut savoir avant de commencer

Wakara n'est pas à télécharger dans le Play Store ou l'App Store. C'est un site web qui peut s'installer comme une application. Une fois installé, il garde une copie de lui-même sur votre appareil et peut s'ouvrir sans Internet.

L'adresse à utiliser, toujours la même :

https://wakara-rtm.vercel.app
Les 3 règles à ne jamais oublier
  1. La toute première ouverture se fait AVEC Internet. C'est là que l'appareil télécharge l'application et que vous créez votre code.
  2. Pas de navigation privée : le navigateur effacerait tout à la fermeture.
  3. Notez votre code de verrouillage dans un endroit sûr (pas sur le téléphone). Si vous l'oubliez, appelez l'administrateur : il peut vous communiquer un code de récupération qui rouvre l'appareil sans rien perdre (voir la section 7).

Ce que vous pourrez faire sans Internet

  • Créer une déclaration de naissance, la modifier, l'enregistrer en brouillon.
  • Photographier la fiche physique.
  • La transmettre au secrétariat (elle partira quand le réseau reviendra).
  • Consulter vos dossiers déjà reçus.

2. Préparation (administrateur, une seule fois)

  1. Se connecter en administrateur sur le site.
  2. Menu Paramètres : vérifier que offline.enabled vaut true (sinon le mode hors ligne est coupé pour tout le monde).
  3. Menu Utilisateurs : créer le compte de chaque agent avec le rôle Agent de collecte.
  4. Agent qui a oublié son code : vérifier son identité (rappel sur un numéro connu), puis menu Appareils hors connexion → Code de récupération de son appareil → saisir un motif et son propre mot de passe → dicter le code. Chaque lecture est inscrite au journal. Jamais pour un appareil volé : le révoquer.
  5. Retenir la limite : 3 appareils au maximum par compte. Le quatrième est refusé tant qu'un ancien appareil n'est pas révoqué (menu Appareils hors connexion).

3. Sur ordinateur (Windows, Mac, Linux)

Navigateur conseillé : Chrome ou Edge.

  1. Ouvrez https://wakara-rtm.vercel.app avec Internet.
  2. Connectez-vous avec votre identifiant et votre mot de passe.
  3. L'écran « Protégez cet appareil » apparaît. Choisissez un code de verrouillage : 8 caractères minimum mêlant lettres et chiffres, ou une phrase de 14 caractères. Les codes évidents (123456) sont refusés.
  4. Laissez la page ouverte environ 10 secondes : l'application se copie sur l'appareil en tâche de fond.
  5. (Conseillé) Installez l'application : cliquez sur l'icône « Installer » à droite de la barre d'adresse, ou menu ⋮ → Installer Wakara. Wakara s'ouvre alors dans sa propre fenêtre, avec une icône sur le bureau.
  6. Faites le test final (section 6).
Ordinateur partagé Choisissez « Continuer sans le mode hors connexion » : vous travaillerez uniquement en ligne et rien ne restera sur la machine.

4. Sur téléphone Android (Chrome)

  1. Ouvrez Chrome et allez sur https://wakara-rtm.vercel.app, avec Internet (Wi-Fi ou données mobiles).
  2. Connectez-vous, puis créez votre code de verrouillage (mêmes règles que ci-dessus).
  3. Restez environ 10 secondes sur l'application.
  4. Installez-la :
    • Touchez le menu ⋮ (en haut à droite de Chrome).
    • Touchez « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
    • Confirmez avec Installer. L'icône Wakara apparaît avec vos autres applications.
  5. À partir de maintenant, ouvrez Wakara depuis cette icône.
  6. Si le téléphone demande l'autorisation d'utiliser la caméra, acceptez : elle sert à photographier la fiche.
  7. Faites le test final (section 6).
À éviter sur Android
  • Ne videz pas les données de Chrome (« Effacer les données de navigation ») : cela supprimerait le code et les saisies non envoyées.
  • Vérifiez que l'économiseur de batterie ne bloque pas Chrome en arrière-plan.

5. Sur iPhone / iPad (Safari)

Sur iPhone, l'installation est obligatoire Dans Safari, le navigateur peut effacer les données d'un site après 7 jours sans visite. Installée sur l'écran d'accueil, l'application est protégée de cet effacement.
  1. Ouvrez Safari (pas un autre navigateur) et allez sur https://wakara-rtm.vercel.app, avec Internet.
  2. Touchez le bouton Partager (le carré avec une flèche vers le haut, en bas de l'écran).
  3. Faites défiler la liste et touchez « Sur l'écran d'accueil », puis Ajouter.
  4. Fermez Safari. Ouvrez Wakara depuis la nouvelle icône.
  5. Dans l'application ouverte depuis l'icône : connectez-vous, créez votre code de verrouillage, puis attendez environ 10 secondes. L'application installée a son propre espace de stockage : ce que vous feriez dans Safari ne serait pas retrouvé dans l'icône.
  6. Faites le test final (section 6).
À éviter sur iPhone
  • Ne supprimez pas l'icône Wakara : cela supprime aussi les données locales.
  • Même installée, synchronisez régulièrement.

6. Test final : vérifier que ça marche

À faire une fois sur chaque appareil, avec un compte de test, avant le travail réel.

  • Appareil connecté, Wakara ouvert et chargé depuis au moins 10 secondes.
  • Coupez tout le réseau : mode avion (ou Wi-Fi et données coupés). Sur ordinateur : touche F12, onglet Réseau, case Hors connexion.
  • Fermez complètement Wakara puis rouvrez-le : il doit s'ouvrir sur l'écran de code.
  • Saisissez le code : vos dossiers déjà reçus sont visibles.
  • Créez une déclaration (date, heure, lieu, sexe de l'enfant au minimum), ajoutez une photo, enregistrez. Elle porte une référence LOCAL-… et l'indicateur orange « Sur cet appareil ».
  • Touchez « Transmettre au secrétariat » : le dossier passe en « Transmis ».
  • Rétablissez le réseau. Après quelques secondes, l'indicateur passe au vert « En ligne » et la référence devient WKR-….
  • Le secrétariat voit bien le dossier dans sa liste.
Si « étape 3 » échoue (page blanche hors ligne) L'application n'avait pas fini de se copier. Reconnectez-vous, attendez plus longtemps sur la page, puis recommencez le test.

7. Les bons réflexes au quotidien

  • Synchronisez dès que vous avez du réseau, et au moins une fois par jour. Un appareil verrouillé ou une page fermée n'envoie rien.
  • En haut de l'écran, la pastille indique En ligne ou Hors connexion et le nombre d'opérations en attente.
  • Le téléphone se verrouille seul après 15 minutes d'inactivité. Le code est redemandé à chaque ouverture, même sans Internet.
  • Une bannière rouge apparaît si des saisies attendent depuis plus de 24 heures.
  • Page Synchronisation : bouton de sauvegarde de secours. Gardez le fichier ailleurs que sur le téléphone (par exemple envoyé par courriel à vous-même).
  • Gardez la date et l'heure du téléphone en réglage automatique : le serveur corrige ou écarte les dates trop fausses.
  • Code de verrouillage oublié : écran de code → « Code oublié ? » → appelez l'administrateur. Après avoir vérifié qui vous êtes, il vous dicte un code de récupération (24 caractères, par groupes de 4). Touchez « J'ai un code de récupération », saisissez-le et choisissez un nouveau code : toutes vos déclarations non envoyées sont conservées. Le code ne sert qu'une fois.
  • Double authentification (si votre compte l'utilise) : après le mot de passe, saisissez le code à 6 chiffres de votre application d'authentification, ou un code de secours. Téléphone perdu : contactez l'administrateur.
  • Quand un bandeau propose « Recharger », une nouvelle version est prête : rechargez à un moment calme, avec du réseau.
  • Téléphone perdu ou volé : prévenez tout de suite l'administrateur, qui révoque l'appareil.

Que veulent dire les indicateurs sur un dossier ?

IndicateurSignification et action
En ligne (vert)Le dossier est sur le serveur. Rien à faire.
Sur cet appareil (orange)Le dossier n'existe que sur votre appareil (référence LOCAL-). Il partira au retour du réseau.
Modifications à envoyer (orange)Vos derniers changements n'ont pas encore été envoyés. Ils partiront au retour du réseau.
Envoi en cours (bleu)Patientez.
Refusée par le serveur (rouge)Information manquante par exemple. Ouvrez le dossier : le motif est affiché. Corrigez puis « Renvoyer ».
Conflit à résoudre (rouge)Le dossier a changé sur le serveur pendant votre travail hors ligne. Choisissez la version à garder : rien n'est écrasé sans votre choix.

Pour l'équipe : à vérifier avant le déploiement Les tests automatiques couvrent Chrome sur ordinateur. Les téléphones réels (Android et iPhone) ne sont pas testés automatiquement : faites le test final de la section 6 sur au moins un Android et un iPhone avant de remettre les appareils aux agents. Les libellés des menus peuvent varier légèrement selon la version d'Android ou d'iOS.
